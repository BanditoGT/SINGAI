# Evidencia reproducible — 14 de septiembre de 2026

## Pruebas automatizadas

Comando ejecutado desde la raíz:

```text
pnpm test
```

Resultado observado:

```text
tests 16
pass 16
fail 0
duration_ms 193.4871
```

Las suites cubren catálogo y existencia de videos, XP y racha, vidas, hashing
con scrypt, firma y expiración JWT, resumen de tokens y traducción/deletreo.

## Compilación

```text
pnpm build
```

Vite transformó 1690 módulos y generó la interfaz correctamente. Produjo una
advertencia no bloqueante porque el paquete JavaScript minificado supera 500 kB.

## Integración local aislada

Comando reproducible:

```text
pnpm evidence:integration
```

El script usa puertos altos aleatorios y una copia temporal del código, catálogo,
bases y bandeja de salida. No modifica `datos/auth.db`, `datos/profiles.db` ni la
bandeja de la copia de trabajo.

Resultados esperados y observados en la ejecución de referencia:

| Paso | Resultado |
|---|---|
| Health de núcleo, perfil y correo | `200` en los tres |
| Catálogo | `200`, 105 señas, 5 unidades |
| Registro | `201`, requiere verificación, correo en bandeja local |
| Consumo del enlace | `200`, token devuelto |
| Consulta de perfil | `200`, XP inicial 0 |
| Completar primera lección | `200`, XP 20, racha 1 |
| Perfil interno sin `x-service-key` | `403` |

Hallazgo conocido: la respuesta del consumo del enlace presenta
`user.verified=false` porque serializa la fila leída antes del `UPDATE`. La
consulta posterior autenticada funciona, por lo que la cuenta sí queda verificada.
